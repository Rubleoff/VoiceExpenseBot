# Telegram-бот для учёта расходов

## Краткое описание

Этот проект представляет собой Telegram-бота для учёта личных расходов. Пользователь может добавлять расходы текстом или голосовым сообщением.

Основной формат ввода:

```text
250 еда кофе
1200 транспорт такси
500 продукты
```

Бот сохраняет расходы в локальную базу данных SQLite (`expenses.db`) и позволяет смотреть статистику за день, неделю и месяц.

Дополнительная функция проекта — голосовой ввод. Пользователь может отправить голосовое сообщение, бот скачает его, конвертирует через `ffmpeg`, распознает речь с помощью локальной модели Vosk и предложит подтвердить результат перед записью в базу данных.

# Основные файлы проекта

## `bot.py`

Главный файл Telegram-бота. В нём находятся обработчики команд, обработка текстовых сообщений, обработка голосовых сообщений и inline-кнопки подтверждения.

Основные команды:

```text
/start — показать инструкцию
/help — показать помощь
/add — добавить расход через команду
/today — показать расходы за сегодня
/week — показать расходы за последние 7 дней
/month — показать расходы за текущий месяц
/history — показать последние расходы
/delete_last — удалить последний расход
/delete ID — удалить расход по ID
/voice_status — проверить доступность голосового ввода
```

## `database.py`

Файл содержит всю логику работы с базой данных SQLite:

```text
создание базы данных;
создание таблицы расходов;
добавление расходов;
получение статистики;
получение истории расходов;
удаление расходов.
```

Файл базы данных `expenses.db` создаётся автоматически при первом запуске бота.

## `parser.py`

Файл отвечает за разбор пользовательского ввода.

Он может обработать обычный текст:

```text
250 еда кофе
```

А также простые суммы, написанные словами:

```text
двести пятьдесят еда кофе
одна тысяча двести транспорт такси
```

## `speech.py`

Файл отвечает за голосовой ввод:

```text
проверяет наличие модели Vosk;
проверяет наличие ffmpeg;
конвертирует голосовое сообщение из .ogg в .wav;
распознаёт речь через Vosk.
```

# Настройка `.env`

Проект использует файл `.env` для хранения настроек.

Создай файл `.env` в корне проекта:

```env
BOT_TOKEN=your_telegram_bot_token_here
DB_PATH=expenses.db
VOSK_MODEL_PATH=models/vosk-model-small-ru-0.22
```

## `BOT_TOKEN`

Токен Telegram-бота, который выдаёт `@BotFather`.

Пример:

```env
BOT_TOKEN=123456789:AAExampleToken
```

Нельзя публиковать этот токен на GitHub.

## `DB_PATH`

Путь до файла базы данных SQLite.

Рекомендуемое значение:

```env
DB_PATH=expenses.db
```

Файл `expenses.db` создаётся автоматически при первом запуске бота.

## `VOSK_MODEL_PATH`

Путь до скачанной и распакованной модели Vosk.

Рекомендуемое значение:

```env
VOSK_MODEL_PATH=models/vosk-model-small-ru-0.22
```

Если модель отсутствует, бот всё равно сможет работать в текстовом режиме, но голосовой ввод будет недоступен.

# Установка на macOS

## 1. Создать папку проекта

```bash
mkdir expense_bot
cd expense_bot
```

## 2. Создать виртуальное окружение

```bash
python3 -m venv .venv
```

Активировать виртуальное окружение:

```bash
source .venv/bin/activate
```

## 3. Установить Python-зависимости

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

## 4. Установить Homebrew, если его нет

Сайт Homebrew:

```text
https://brew.sh/
```

## 5. Установить `ffmpeg` на macOS

```bash
brew install ffmpeg
```

Страница `ffmpeg` в Homebrew:

```text
https://formulae.brew.sh/formula/ffmpeg
```

Проверить установку:

```bash
ffmpeg -version
```

Если терминал показал информацию о версии, значит `ffmpeg` установлен правильно.

Из корня проекта выполни:

```bash

curl -L -o models/vosk-model-small-ru-0.22.zip https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip

unzip models/vosk-model-small-ru-0.22.zip -d models

rm models/vosk-model-small-ru-0.22.zip
```

После распаковки структура должна быть такой:

```text
models/
└── vosk-model-small-ru-0.22/
    ├── am/
    ├── conf/
    ├── graph/
    ├── ivector/
    └── README
```

Официальный список моделей Vosk:

# Установка `ffmpeg` на Windows

Официальная страница загрузки FFmpeg:

```text
https://ffmpeg.org/download.html
```

Удобные Windows-сборки:

```text
https://www.gyan.dev/ffmpeg/builds/
```

Порядок установки:

1. Открой сайт:

```text
https://www.gyan.dev/ffmpeg/builds/
```

2. Скачай архив:

```text
ffmpeg-release-essentials.zip
```

3. Распакуй архив, например, в папку:

```text
C:\ffmpeg
```

4. Найди внутри папку `bin`.

Путь будет примерно таким:

```text
C:\ffmpeg\ffmpeg-...\bin
```

5. Добавь эту папку в переменную среды `PATH`.

6. Закрой и заново открой PowerShell.

7. Проверь установку:

```powershell
ffmpeg -version
```

Если появилась информация о версии, `ffmpeg` установлен правильно.

# Голосовой ввод

Голосовой ввод является дополнительной функцией.

Бот может работать без Vosk и `ffmpeg`, но в таком случае будет доступен только текстовый ввод.

Если голосовой ввод недоступен, бот покажет причину.

Например:

```text
Голосовой ввод сейчас недоступен.

Причина: не установлен ffmpeg
```

Или:

```text
Голосовой ввод сейчас недоступен.

Причина: модель Vosk не найдена по пути: models/vosk-model-small-ru-0.22
```

# Возможные ошибки

## Ошибка `No matching distribution found for vosk>=0.3.45`

В `requirements.txt` нужно использовать:

```txt
vosk==0.3.44
```

После этого выполнить:

```bash
pip install -r requirements.txt
```

## Ошибка `ffmpeg не установлен`

Проверь командой:

```bash
ffmpeg -version
```

Если команда не найдена, установи `ffmpeg` и перезапусти терминал.

## Ошибка `модель Vosk не найдена`

Проверь, что путь в `.env` совпадает с реальным названием папки модели.

Пример:

```env
VOSK_MODEL_PATH=models/vosk-model-small-ru-0.22
```

Если папка после распаковки называется иначе, измени `VOSK_MODEL_PATH`.

## Бот не запускается

Проверь, что в `.env` есть реальный токен:

```env
BOT_TOKEN=твой_реальный_токен
```

Также проверь, что виртуальное окружение активировано и зависимости установлены.

# Краткое описание для отчёта

Проект представляет собой Telegram-бота для учёта личных расходов. Пользователь может добавлять расходы текстом или голосовым сообщением. Данные сохраняются в локальную базу данных SQLite. Для голосового ввода используется локальное офлайн-распознавание речи Vosk. Перед сохранением расхода, полученного из голосового сообщения, бот показывает пользователю расшифровку и просит подтвердить корректность данных через inline-кнопки. Это снижает риск ошибочной записи данных в базу при неточном распознавании речи.
